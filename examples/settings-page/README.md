# Settings page example

This is the runnable example produced by:

```bash
ovlira init ./settings-page
ovlira add page.settings --cwd ./settings-page
cd settings-page
npm install
npm run dev
```

The page uses the application shell, page header, cards, inputs, selects, buttons, and alerts. Its loading, error, and success states can be switched from the preview controls so the recipe can be adapted to a real save flow instead of relying on placeholder markers.
