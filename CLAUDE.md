# Ovlira agent guidance

Use Ovlira progressively: search before inventing, inspect before using, and prefer recipes for complete screens. Add only the needed building blocks, use the project-owned `src/styles/ovlira-theme.css` and approved `--ov-*` tokens, include required states, and run `ovlira check --json` before finishing. Keep custom CSS deliberate and local when the catalogue cannot express the requirement.
