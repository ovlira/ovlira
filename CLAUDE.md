# Ovlira agent guidance

`DESIGN.md`, `ui.html`, and approved screenshot baselines are the visual authority. Do not choose or revise palette, typography, radius, density, motion, or component styling. Use Ovlira progressively: search before inventing, inspect before using, and prefer recipes for complete screens. Add only the needed building blocks, use the project-owned `src/styles/ovlira-theme.css` and approved `--ov-*` tokens, include required states, render at the required viewports, and run `ovlira check --json` before finishing. Report visual deviation instead of inventing a replacement style.
