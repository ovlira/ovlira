# Ovlira agent guidance

`DESIGN.md`, `ui.html`, and approved screenshot baselines are the visual authority. Do not choose or revise palette, typography, radius, density, motion, or component styling. Use Ovlira progressively: `npm run ovlira -- search`, then `inspect`, then prefer a recipe. Component add returns a package import; recipe add generates local composition. Use the project-owned `src/styles/ovlira-theme.css` and approved `--ov-*` tokens, include required states, render at the required viewports, and run `npm run ovlira -- check --json` before finishing. Report visual deviation instead of inventing a replacement style.
