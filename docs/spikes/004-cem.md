# Spike 004 — Custom Elements Manifest

## Question

Should CEM be generated, consumed, or merely documented?

## Experiment

Configured `@custom-elements-manifest/analyzer` with the Lit analyzer over `src/components/*.ts` and added API JSDoc-compatible declarations. The command is `npm run manifest`.

## Result

CEM can describe the public runtime surface, but Ovlira guidance needs a separate stable JSON shape.

## Decision

Generate `custom-elements.json` as a companion artifact and keep `src/catalogue/components.json` as the compact agent-facing sidecar.

## Consequence for Ovlira

The API and design guidance can evolve independently while remaining linkable by stable component IDs and tags.

Reference: [Custom Elements Manifest analyzer](https://custom-elements-manifest.open-wc.org/analyzer/getting-started/).
