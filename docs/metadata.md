# Metadata

Ovlira has two metadata layers.

The runtime layer is `custom-elements.json`, generated by the Custom Elements Manifest analyzer. It describes custom-element tags, class members, attributes, slots, events, CSS parts, and CSS custom properties.

The Ovlira layer is `src/catalogue/components.json` and `src/catalogue/recipes.json`. It is deliberately compact and adds:

- stable IDs, categories, and searchable tags;
- use/avoid guidance;
- required props and states;
- disallowed composition;
- recipe component lists, composition rules, and examples.

`ovlira inspect <id> --json` exposes the sidecar descriptor. CEM remains available as a package artifact for tooling that needs implementation-level API detail.
